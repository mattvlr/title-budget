What it looks like

How it was checked

  • 55 tests pass from the exact zip a buyer downloads, in a clean virtualenv on Windows 11 / Python 3.12.
  • The envelope fit was recomputed independently. A separate OLS over the same 35 stored cycles returns slope 0.16502 and intercept 1.61 — identical to what the app prints.
  • Zero JavaScript. No <script>, no onclick, no listener in any template; no external URL; and no requests, urllib or socket import anywhere in the package.
  • A Windows timezone defect was found and fixed before packaging — Windows ships no IANA database, so every zone silently fell back to UTC and filed interval readings under the wrong local hour.

Not included

  • The headline anomaly detectors cannot be demonstrated. The seeded demo house is clean, so the findings panel prints “Nothing anomalous”, and the dead-meter and late-fee detectors have no test covering them. You would be buying those on a reading of the code, not on a demonstration.
  • No utility login, no API, no scraping, no PDF bill parsing. You import CSV or Green Button files you download yourself.
  • UA is a range because furnace efficiency is unmeasured, and the field EER is a lower bound — latent load is invisible to cooling degree days.
  • It refuses to fit below MIN_CYCLES = 6. No sensors, no thermostat, no solar, no equipment-sizing verdict, no multi-house, no mobile app, no support.
  • thermal.py is 625 lines with 13 tests and is not wired to any page — the web layer computes its own fits.
  • Not an energy audit, and it performs no safety function.
