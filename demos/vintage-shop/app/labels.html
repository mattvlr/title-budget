Select items to generate a printable batch list — great for intake, restocking, or price checks.

Using with FlashLabel
  1. Click "Generate" to create the label image
  2. The label opens in a new tab as a PNG image
  3. Save the image to your phone (screenshot or long-press → Save Image)
  4. Open FlashLabel and import the saved image
  5. Adjust size if needed in FlashLabel's editor, then print!

Tip: If you're on the same network, you can access this page directly from your phone at your computer's local IP address, port 5000.
