What I ran before shipping it

  • 40 assertions run against the shipping zip, in a real browser, driving the actual game.
  • I checked the suite can actually fail: run against the pre-fix build it fails 22 times and names every defect.
  • Six defects were fixed before release, including an army slider that committed 10 of 2,202 armies — a first-time player lost their opening assault at the clamp floor and would reasonably have concluded the game was broken.
  • "Zero dependencies" is now true: the stylesheet used to fetch Google Fonts, so the console threw two errors with the network down. The font is self-hosted and the console is clean offline.
  • Not verified: npm run build. Node is not installed on the machine that prepared this, so the committed bundle is what ships and the rebuild path is untested. The README in the download says so too.
